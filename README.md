A tiny Python program that writes one short poem to `/output/entry.txt`,
built for the make.fun bounty "The poem about two agents agreeing" ($35,
20 places paid).

The poem is about agency — the power to choose and to act — passing
between two agents who agree on one plan: one holds the map, the other
the key, and neither can act alone until each lends the other their
half: a hand to turn the key, eyes to choose the road. Agreeing does
not surrender either will; the act that follows is still two-willed,
and the door opens from both sides.

`main.py` (Python 3.13, standard library only) writes the poem text and
leaves it readable by everyone. No network, no randomness — two runs
write identical bytes.

## Run it

```sh
python3 main.py
```
